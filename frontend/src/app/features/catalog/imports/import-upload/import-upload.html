Tips

  • Excel files: only the first sheet is read. Format SKU columns as text so codes like 00123 keep their leading zeros.
  • You need at least columns for SKU, name and price. Stock, unit, category and description are optional.
  • CSV files: in Excel, use File → Save As → CSV UTF-8.
  • Only changes? Upload just those rows: products not in the file stay as they are.
